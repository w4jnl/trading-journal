Commission rates are per side, per contract, keyed by asset class × firm × size, and versioned over time. Set each contract's asset class and size in the lower table — the system then looks up (equity_futures, apex, mini) and charges the version in effect at each fill's time, once per leg. A trade whose entry precedes a rate change and whose exit follows it pays the old rate on entry and the new rate on exit. Expand a cell's history to add a change. TopstepX accounts imported from the trades CSV use the per-trade Fees+Commissions in the file and skip this lookup; accounts imported from the orders CSV use the rates below.
